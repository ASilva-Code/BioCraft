# BioCraft

**BioCraft** é uma wiki construída em HTML avançado sobre o universo de *Minecraft*, funcionando como uma
enciclopédia virtual de biomas, criaturas, estruturas e dicas de sobrevivência.

O projeto foi desenvolvido como atividade acadêmica com o objetivo de aplicar, em conjunto, todo o conteúdo
estudado nas aulas de HTML: tags básicas, meta tags, tabelas e formulários, além das tags semânticas e
avançadas vistas mais recentemente (multimídia, elementos interativos e marcação avançada de texto).

## Como navegar

Abra `html/main.html` no navegador. A partir dele é possível chegar a qualquer outra página do site através
do menu de "Conteúdos" ou dos links de menu principal presentes no topo de cada página.

## Tecnologias e regras seguidas

- **Apenas HTML** — sem uso de CSS ou JavaScript, conforme pedido na atividade.
- Tags semânticas em todas as páginas: `header`, `nav`, `main`, `article`, `section`, `aside` e `footer`.
- Multimídia: `audio` com controles (trilhas sonoras da Selva), `video` local com controles (documentário da
  Selva, em `.mp4`) e imagens organizadas com `figure`/`figcaption`.
- Formulário avançado (`html/sobrevivencia.html`), com campos `date`, `color`, `range` e `file`, validação
  `required`, `placeholder` e sugestões via `datalist`.
- Elemento interativo `details`/`summary` nas listas de biomas e criaturas.
- Marcação avançada de texto: `abbr`, `mark`, `blockquote`, `cite`, `del`, `ins` e `progress`.

## Fonte das informações

O conteúdo textual foi baseado em informações da [Minecraft Wiki em português](https://pt.minecraft.wiki/).
